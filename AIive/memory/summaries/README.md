# 总结记忆

本目录用于存储定期总结。

## 记忆类型

- 每日总结
- 每周总结
- 每月总结
- 项目总结
- 学习总结

## 文件格式

每个总结文件建议包含：

```text
## YYYY-MM-DD HH:mm

### Source
总结来源。

### Content
总结内容。

### Type
summary

### Scope
适用场景。

### Confidence
high / medium / low

### Notes
备注。
```

## 示例

### daily_summary_2026-07-02.md

```text
## 2026-07-02 18:51

### Source
每日总结

### Content
今天开始开发AIive项目，完成了目录结构和文档初始化。

### Type
summary

### Scope
项目进展

### Confidence
high

### Notes
第一版自举内核开发中。
```
