# 实验

本目录用于存储实验性代码和功能。

## 实验类型

- 新功能实验
- 性能优化实验
- 架构改进实验
- 用户体验实验

## 实验格式

每个实验建议包含：

```text
## experiment_name

- Created At:
- Source:
- Description:
- Goals:
- Implementation:
- Results:
- Status: planned / in_progress / completed / failed
- Notes:
```

## 示例

### memory_hit_experiment

```text
## memory_hit_experiment

- Created At: 2026-07-02
- Source: 用户需求
- Description: 实验记忆hit机制
- Goals: 验证记忆hit统计的可行性和效果
- Implementation: 在memory_router中实现hit统计
- Results: 待实验
- Status: planned
- Notes: 记忆运行机制修改请求
```
