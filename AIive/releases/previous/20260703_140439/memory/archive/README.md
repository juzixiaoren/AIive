# 归档记忆

本目录用于存储低频、过期但可能仍有用的记忆。

## 记忆类型

- 低频使用的偏好
- 过期的事件
- 历史反馈
- 旧的总结

## 文件格式

每个归档文件建议包含：

```text
## YYYY-MM-DD HH:mm

### Source
原始来源。

### Content
归档内容。

### Type
archive

### Scope
适用场景。

### Confidence
high / medium / low

### Notes
备注。
```

## 示例

### old_preference.md

```text
## 2026-07-02 18:51

### Source
用户偏好

### Content
用户曾经的偏好，现在不再使用。

### Type
archive

### Scope
历史记录

### Confidence
low

### Notes
已归档，不再主动使用。
```
