### 2.2 统一消息接口

```typescript
// adapters/types.ts

interface ChannelMessage {
  channelType: 'web' | 'telegram' | 'discord';
  channelId: string;        // 频道/群组 ID
  userId: string;           // 发送者 ID
  userName: string;         // 发送者名称
  content: string;          // 消息内容
  replyTo?: string;         // 回复的消息 ID
  attachments?: Attachment[];
  timestamp: string;
}

interface ChannelAdapter {
  name: string;
  
  // 启动适配器（连接 Bot API）
  start(): Promise<void>;
  
  // 停止适配器
  stop(): Promise<void>;
  
  // 发送消息到渠道
  send(channelId: string, content: string): Promise<void>;
  
  // 注册消息接收回调
  onMessage(handler: (msg: ChannelMessage) => Promise<string>): void;
}
```

### 2.3 Telegram Bot 适配器

```typescript
// adapters/telegram.ts

import { Telegraf } from 'telegraf';

class TelegramAdapter implements ChannelAdapter {
  name = 'telegram';
  private bot: Telegraf;
  
  constructor(token: string) {
    this.bot = new Telegraf(token);
  }
  
  async start() {
    this.bot.launch();
  }
  
  async stop() {
    this.bot.stop();
  }
  
  async send(chatId: string, content: string) {
    // Markdown 格式发送，超长消息自动分段
    const chunks = splitMessage(content, 4096);
    for (const chunk of chunks) {
      await this.bot.telegram.sendMessage(chatId, chunk, { parse_mode: 'MarkdownV2' });
    }
  }
  
  onMessage(handler: (msg: ChannelMessage) => Promise<string>) {
    this.bot.on('text', async (ctx) => {
      const channelMsg: ChannelMessage = {
        channelType: 'telegram',
        channelId: String(ctx.chat.id),
        userId: String(ctx.from.id),
        userName: ctx.from.username || ctx.from.first_name,
        content: ctx.message.text,
        timestamp: new Date().toISOString(),
      };
      
      const reply = await handler(channelMsg);
      await this.send(channelMsg.channelId, reply);
    });
  }
}
```

### 2.4 Discord Bot 适配器

```typescript
// adapters/discord.ts

import { Client, GatewayIntentBits } from 'discord.js';

class DiscordAdapter implements ChannelAdapter {
  name = 'discord';
  private client: Client;
  
  constructor(token: string) {
    this.client = new Client({
      intents: [
        GatewayIntentBits.Guilds,
        GatewayIntentBits.GuildMessages,
        GatewayIntentBits.MessageContent,
      ],
    });
  }
  
  async start() {
    await this.client.login(process.env.DISCORD_TOKEN);
  }
  
  async stop() {
    await this.client.destroy();
  }
  
  async send(channelId: string, content: string) {
    const channel = await this.client.channels.fetch(channelId);
    if (channel?.isTextBased()) {
      const chunks = splitMessage(content, 2000);
      for (const chunk of chunks) {
        await channel.send(chunk);
      }
    }
  }
  
  onMessage(handler: (msg: ChannelMessage) => Promise<string>) {
    this.client.on('messageCreate', async (message) => {
      if (message.author.bot) return;
      // 仅响应 @Bot 或私信
      if (!message.mentions.has(this.client.user!) && !message.channel.isDMBased()) return;
      
      const channelMsg: ChannelMessage = {
        channelType: 'discord',
        channelId: message.channelId,
        userId: message.author.id,
        userName: message.author.username,
        content: message.content.replace(/<@!?\d+>/g, '').trim(),
        timestamp: message.createdAt.toISOString(),
      };
      
      const reply = await handler(channelMsg);
      await this.send(channelMsg.channelId, reply);
    });
  }
}
```

## 3. MCP 服务器集成

### 3.1 MCP 概述

MCP（Model Context Protocol）允许 Agent 连接外部工具服务器，扩展能力边界。

```
AIive Agent
    │
    ├── 内置工具（file_read, file_write, shell_exec, http_request）
    │
    └── MCP 连接
        ├── 本地 MCP Server（如：数据库查询工具）
        ├── 远程 MCP Server（如：搜索引擎 API）
        └── 社区 MCP Server（如：GitHub 集成）
```

### 3.2 MCP 客户端实现

```typescript
// mcp/client.ts

interface MCPServerConfig {
  name: string;
  command: string;       // 启动命令
  args?: string[];
  env?: Record<string, string>;
  enabled: boolean;
}

class MCPClient {
  private servers = new Map<string, MCPConnection>();
  
  // 从配置文件加载 MCP 服务器列表
  async loadConfig(configPath: string): Promise<void>;
  
  // 启动指定的 MCP 服务器
  async connect(serverName: string): Promise<void>;
  
  // 获取所有可用工具
  listTools(): MCPTool[];
  
  // 调用 MCP 工具
  async callTool(serverName: string, toolName: string, input: any): Promise<any>;
  
  // 关闭所有连接
  async disconnectAll(): Promise<void>;
}
```

## 5. 定时调度

### 5.1 调度引擎

```typescript
// scheduler/index.ts

import cron from 'node-cron';

interface ScheduledTask {
  name: string;
  cron: string;          // cron 表达式
  prompt: string;        // 发给 Agent 的指令
  channel?: string;      // 结果推送到哪个渠道
  enabled: boolean;
}

class Scheduler {
  private tasks = new Map<string, cron.ScheduledTask>();
  
  // 从配置加载定时任务
  async loadTasks(configPath: string): Promise<void>;
  
  // 注册定时任务
  register(task: ScheduledTask): void {
    const job = cron.schedule(task.cron, async () => {
      // 创建一个新 Session
      // 发送 prompt 给 Agent
      // 将结果推送到指定渠道
    });
    this.tasks.set(task.name, job);
  }
  
  // 停止所有任务
  stopAll(): void;
}
```

## 10. 风险与注意事项

```
⚠️ P3 关键风险:
1. IM Bot Token 安全 — 必须通过 .env 管理，不纳入版本控制
2. 消息长度限制 — Telegram 4096 字符，Discord 2000 字符，需自动分段
3. 并发消息 — 多渠道同时发消息时的 Session 隔离
4. MCP 服务器稳定性 — 外部 MCP Server 可能不稳定，需要超时和重试
5. 定时任务成本 — 每次定时任务都会消耗 API 调用，需要控制频率

💡 P3 设计原则:
1. 渠道适配器模式 — 新增渠道只需实现 ChannelAdapter 接口
2. 渐进式接入 — 先 Telegram，再 Discord，再 MCP
3. 安全隔离 — 不同渠道的消息不混淆
4. 优雅降级 — IM 不可用时不影响 Web 界面
```
