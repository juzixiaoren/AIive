# AIive 功能验证指南

> 逐个验证，每个场景有操作步骤、期望结果、验证方法  
> 标记：✅ 已验证 / ❌ 未通过 / ⚠️ 部分通过

---

## 启动服务

```bash
# 终端 1：启动 PostgreSQL + Qdrant
docker compose up -d

# 终端 2：启动后端
python3 -m uvicorn aiive.main:app --reload --host 127.0.0.1 --port 8000

# 终端 3：启动前端
cd frontend && npm run dev
```

打开 http://localhost:5173

## 1. 对话能力

### 1.1 基本聊天
```
输入：你好
期望：
  - 有 AI 回复（不是固定句式）
  - 回复下方有 trace_id、thread_id（小字可点击）
验证：查看 trace_id 是否每次都不同
```

### 1.2 多轮对话
```
输入：我叫小明
输入：我喜欢喝咖啡
输入：我叫什么？我喜欢什么？
期望：回复 "小明" 和 "咖啡"
验证：能记住同一对话中的上下文
```

### 1.3 刷新不丢对话
```
操作：发送几条消息 → 刷新浏览器（F5）
期望：
  - 之前消息仍在
  - thread_id 不变（新消息在同一 thread 下）
验证：刷新前后 chat 记录一致
```

## 2. 定时提醒

### 2.1 创建提醒
```
输入：1 分钟后给我发 hi
期望：
  - 立即回复确认（不是 LLM 假装等待）
  - 消息下方出现 📌 执行卡片
验证：
  - 查看"能力"Tab 的"已注册工具"，schedule_reminder 在列表中
  - 等待 ~70 秒，原对话中应出现 Agent 主动生成的 "hi" 回复
  - 数据库中对应 Task 应按 pending → dispatching → completed 流转；不能用固定通知代替 Agent 回复
```

### 2.2 查看提醒列表
```
输入：我有哪些提醒？
期望：列出当前未完成的提醒
验证：回复中包含 task 信息
```

### 2.3 取消提醒
```
操作：先创建提醒 → 记下 task_id → 取消
输入：取消刚才那个提醒
期望：回复确认已取消
验证：到期后通知不出现
```

## 3. 记忆能力

### 3.1 改 AI 称呼
```
输入：以后你叫小爱
期望：回复确认已改名
输入：你叫什么？
期望：回复 "小爱"（不是之前的名字）
验证：重启对话再问，仍回答 "小爱"
```

### 3.2 覆盖旧称呼
```
输入：以后你叫 A
输入：以后你叫 B
输入：你叫什么？
期望：只回答 B（不是 A，不是混用）
验证：数据库 memory_records 表，A 的 lifecycle_state = superseded，B = active
```

### 3.3 改用户称呼
```
输入：以后叫我小李
输入：我叫什么？
期望：回复 "小李"
输入：以后叫我大王
输入：我叫什么？
期望：只回答 "大王"，旧 "小李" 被覆盖
```

### 3.4 忘记记忆
```
输入：忘掉你关于我名字的记忆
期望：回复确认已遗忘
输入：我叫什么？
期望：不再回答之前的名字（说不知道或反问）
```

## 9. 其他能力

### 9.1 查看事件日志
```
操作：切换"事件"Tab
期望：显示事件时间线，如实记录本次 Agent 运行的全部输入与输出
包含类型：用户消息、系统注入(system_injection)、工具调用(tool_call)、工具结果(tool_result)、模型回复、对话结束等
验证：
  - 事件按时间排列，有 type 标签
  - tool_call 事件可展开查看完整输入参数(params)，tool_result 可展开查看完整输出(result)与状态
  - system_injection 事件可展开查看完整系统提示与注入的工具列表
```

### 9.2 查看上下文快照
```
操作：在聊天中点 trace_id → 自动跳转 "上下文" Tab
期望：显示 Stable Prefix、Working Set、注入的记忆、Token 数，以及本次运行的全部 LLM 调用
验证：
  - injected_memory_ids 中有被注入的记忆 ID
  - "LLM 调用"区块列出每次模型调用，可展开查看完整输入消息与输出(内容 + 工具调用)
```

### 9.3 通知查看
```
操作：切换"通知"Tab
期望：有通知时显示红点数字，Tab 内列出通知详情
验证：创建提醒 → 到期后切到通知 Tab → 看到 hi 通知
```
