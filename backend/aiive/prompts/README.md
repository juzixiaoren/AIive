# AIive Prompt Catalog

这里存放会直接发送给模型的稳定提示词模板。业务代码只通过
`get_prompt_registry().render(prompt_id, ...)` 使用模板，不直接读取文件。

## 修改规则

1. 在 `manifest.toml` 中登记稳定的 `prompt_id`、语义版本、消息角色和变量。
2. 模板变量统一写成 `${variable_name}`；JSON 示例中的 `{}` 不需要转义。
3. 修改模板语义时同步提升 `version`。
4. 不要把密钥、用户数据或运行时配置写进模板；它们应作为渲染变量传入。
5. 应用启动时会校验文件、UTF-8、变量契约，并记录目录与各模板的 SHA-256
   指纹。校验失败会阻断启动。

动态运行时数据、工具 Schema、用户记忆和数据库内容不属于静态提示词，
继续由对应服务在运行时组装。
